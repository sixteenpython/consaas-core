# ADR-NA-005: Deterministic Services Own Mechanics

Status: Proposed  
Date: 2026-08-17

## Context

LLMs are useful for interpretation but unreliable for exact arithmetic, ordering, IDs, persistence, and provenance.

## Decision

Deterministic code owns parsing mechanics where practical, scene numbering/order, IDs, validation, SIS arithmetic, thresholds, momentum series, versioning, persistence, provenance traversal, compilation, and report assembly. LLMs interpret narrative evidence and formulate bounded recommendations.

## Consequences

Analyses are replayable and numeric drift is prevented. Structured model output needs additional validation and evidence packets. An LLM can propose a pillar score but cannot calculate or overwrite aggregates.
