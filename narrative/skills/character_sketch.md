# Character Sketch

## Purpose
Propose playable characters whose desires and contradictions generate the selected plot.

## Method
For each character define role, external objective, internal need, motivation, ideology, fear, contradiction, behavioral signature, voice and arc. Avoid biography that never changes action. Ensure the antagonist is a coherent counterforce rather than merely evil.

## Output contract
Return two to four distinct options. Explain how each creates conflict and reveal all generated names and details as proposals requiring author approval.
