# CareerSim

CareerSim is built for Indian students evaluating the ROI of expensive overseas undergraduate,
master's and PhD opportunities. It compares INR-normalised all-in cost, funding structure,
destination, employment evidence, post-study work pathways, India-return versus overseas earning
scenarios, payback horizon and compound downside risk. It does not promise admission, employment,
salary, visa or migration outcomes.

The product owns `SKILL.md`, `questions.json`, `decision_policy.json`, its GKA schema, sources and
deterministic engine. The shared Decision Studio owns only the consultation and artifact lifecycle.
