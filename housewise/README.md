# HouseWise

HouseWise is an India-first residential Real Estate Intelligence product. Its Foundation MVP compares
city-level search-zone archetypes using affordability, liveability, liquidity, access, yield, growth
and downside risk. It is not a listing service, property valuation, title opinion or purchase advice.

The product owns `SKILL.md`, `questions.json`, `decision_policy.json`, its GKA schema, sources and
deterministic engine. Property-level diligence remains mandatory.
